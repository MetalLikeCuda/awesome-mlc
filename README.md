# Awesome MetalLikeCuda
A list of community maintained metal tools, frameworks, libraries and resources

- <a href="https://github.com/MetalLikeCuda/gpumkat">gpumkat</a> - a GPU kernel analysis tool for Metal with many features ranging from analyzing performance, cache hit rates, interface metrics, gpu software states, shader optimization recommendations, stack traces, recording timelines, traces and more.

- <a href="https://github.com/marcogva-hub/mlx-flashattention-steel/">mlx-flashattention-steel</a> - a Metal Flash Attention + serving-oriented runtime layer for MLX on Apple Silicon. It provides high-performance attention kernels, runtime helpers, and cache abstractions for dense training/inference plus modern serving flows.

- <a href="https://github.com/philipturner/metal-flash-attention">metal-flash-attention</a> - FlashAttention implemented and optimized for Apple Silicon using Metal compute shaders.

- <a href="https://github.com/tinygrad/tinygrad/tree/master/tinygrad/runtime">tinygrad Metal runtime</a> - Lightweight ML runtime with dynamic Metal kernel generation and graph execution.

- <a href="https://github.com/iree-org/iree/tree/main/runtime/src/iree/hal/drivers/metal">IREE Metal backend</a> - MLIR-based compiler/runtime system targeting Metal GPU execution.

- <a href="https://github.com/tracel-ai/burn">Burn framework</a> - Rust ML framework exploring portable GPU compute and backend tuning systems.

- <a href="https://github.com/dipampaul17/KVSplit">KVSplit</a> - Differentiated KV Cache Quantization for Apple Silicon

- <a href="https://github.com/MetalLikeCuda/mCemm">mCemm</a> - a GEMM (General Matrix Multiply) kernel generator for Apple Metal.

- <a href="https://github.com/Mininglamp-AI/cider">cider</a> - Cider provides online activation quantization operators absent in MLX, with custom int-matmul kernels built as MLX custom primitives supporting full lazy evaluation. 

- <a href="https://github.com/arozanov/turboquant-mlx">turboquant-mlx</a> - TurboQuant KV cache compression for MLX on Apple Silicon.

- <a href="https://github.com/youssofal/MTPLX">MTPLX</a> - Native MTP speculative decoding on Apple Silicon

- <a href="https://github.com/hanxiao/mlx-vis">mlx-vis</a> - Pure MLX implementations of UMAP, t-SNE, PaCMAP, LocalMAP, TriMap, DREAMS, CNE, MMAE, and NNDescent for Apple Silicon.

- <a href="https://github.com/tashiscool/fp8-mps-metal">fp8-mps-metal</a> - Custom FP8 compute kernels for Apple Silicon (MPS) — fixing what PyTorch doesn't support yet.

- <a href="https://github.com/Harperbot/metal-guard">metal-guard</a> - MetalGuard is a GPU safety layer for MLX on Apple Silicon which prevents MLX models from rebooting your mac on kernel-panics.

- <a href="https://github.com/ssmall256/demucs-mlx">demucs-mlx</a> - Split any song into its individual stems — vocals, drums, bass, and other instruments — directly on your Mac.
